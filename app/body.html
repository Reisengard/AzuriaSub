        AIで文字起こし

        動画の音声を Google の Gemini API に送り、単語ごとのタイミングが付いた字幕を作ります。今ある字幕は置き換えられます。

        音声が Google に送信されます。映像は送信されません。無料枠の API キーでは、送信した内容が Google の製品改善に使われることがあります。

        キーは Google AI Studio で作れます。このブラウザにだけ保存され、プロジェクトファイルには含まれません。

        7分までの動画に対応しています。歌や固有名詞は聞き間違えることがあるので、作成後に字幕を確認してください。

        字幕編集の流れ

        1. 動画を読み込む。動画は「動画設定」で、書き出す縦横比（9:16・4:5・1:1・16:9）、トリム、クロップを選びます。
        2. 文字起こしを入れる。「AIで文字起こし」で音声から自動で作るか、単語タイムスタンプ JSON、SRT、VTT を読み込むか、台本を貼り付けて「同期」で合わせます。
        3. スタイルを選ぶ。エフェクトは「エフェクト」で自分で選びます（ランダムに決めることもできます）。位置ボックスは動画の上でドラッグして決めます。
        4. タイムラインで整える。字幕の境界をドラッグし、トラックを分けて重ねることもできます。
        5. 書き出す。字幕付き MP4 は、このブラウザの中で作られます。
        6. 字幕ファイルも使う。「書き出し」の「SRT を書き出す」で、字幕だけを SRT ファイルに保存できます。
